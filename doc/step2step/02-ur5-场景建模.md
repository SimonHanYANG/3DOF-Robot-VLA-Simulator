## 目标
从 MuJoCo Menagerie 获取 UR5e 机械臂模型，设计并集成简化平行二指夹爪，组装完整的取放仿真场景（桌面、几何体物体、相机传感器）。

## 前置条件
- S01 完成：MuJoCo 已安装并可运行

## 实现细节

### 1. UR5e Menagerie 集成

从 `google-deepmind/mujoco_menagerie` 仓库获取 UR5e 模型：

```bash
# 克隆 Menagerie（或作为 git submodule）
git clone https://github.com/google-deepmind/mujoco_menagerie.git tmp_menagerie
# 复制 UR5e 目录到项目
cp -r tmp_menagerie/universal_robots_ur5e sim/assets/ur5e/
rm -rf tmp_menagerie
```

只保留 UR5e 臂模型（不使用 Robotiq 夹爪）：
- `ur5e.xml` — 6-DOF 机械臂 MJCF 定义
- `meshes/` — STL 碰撞和视觉 mesh 文件

UR5e 关节（6 个旋转关节）：
| 关节名 | 轴 | 限位 |
|--------|-----|------|
| shoulder_pan | Z | ±360° |
| shoulder_lift | Y | ±360° |
| elbow | Y | ±360° |
| wrist_1 | Y | ±360° |
| wrist_2 | Z | ±360° |
| wrist_3 | X | ±360° |

### 2. 简化平行二指夹爪

在 `sim/assets/ur5e/gripper.xml` 中定义夹爪 MJCF：

```xml
<!-- 夹爪结构 -->
<body name="gripper_base" pos="0 0 0" childbody="wrist_3_link">
  <!-- 手掌 -->
  <geom name="palm" type="box" size="0.02 0.04 0.01" .../>
  <!-- 左手指 -->
  <body name="finger_left" pos="0 0.005 -0.02">
    <joint name="finger_left_joint" type="slide" axis="0 1 0" range="0 0.04"/>
    <geom name="finger_left_geom" type="box" size="0.005 0.005 0.02"
          friction="1.0 0.005 0.001" contype="1" conaffinity="1"/>
  </body>
  <!-- 右手指（mimic 左手指） -->
  <body name="finger_right" pos="0 -0.005 -0.02">
    <joint name="finger_right_joint" type="slide" axis="0 -1 0" range="0 0.04"
           mimic="finger_left_joint"/>
    <geom name="finger_right_geom" type="box" size="0.005 0.005 0.02"
          friction="1.0 0.005 0.001" contype="1" conaffinity="1"/>
  </body>
</body>
```

关键参数：
- 手指行程：0 ~ 0.04m
- 手指摩擦：μ=1.0（橡胶材质，保证抓取稳定）
- 手掌固定于 UR5e `wrist_3_link`
- 单一执行器控制两个手指（mimic）

### 3. 完整场景组装

`sim/assets/scene.xml` 主场景包含：

```
worldbody
  ├── UR5e 基座（固定，pos 使工作空间覆盖桌面）
  │   └── 6 个旋转关节链
  │       └── 夹爪（gripper_base → finger_left + finger_right）
  ├── 桌面（box geom, 0.8×0.8×0.02m, z=0）
  ├── 几何体物体（freejoint）
  │   ├── obj_cube（红，0.04m 边长）
  │   ├── obj_sphere（绿，半径 0.025m）
  │   └── obj_cylinder（蓝，r=0.015m, h=0.06m）
  ├── 目标标记（半透明小球 site，可动态更新位置）
  └── 相机
      ├── top_cam（z=0.8 垂直向下，fovy=60）
      └── wrist_cam（附着于夹爪手掌，朝向接近方向）
```

碰撞过滤：
- 手臂连杆：`contype="0" conaffinity="0"`（禁用自碰撞）
- 夹爪手指：`contype="1" conaffinity="1"`（需与物体碰撞）
- 物体：`contype="1" conaffinity="1"`

执行器：
- 6 个 position actuator 对应 6 个关节（kp 参考 Menagerie 默认值）
- 1 个 actuator 控制夹爪手指

### 4. 物体定义文件

`sim/assets/objects.xml` 定义可互换的物体模板，方便后续扩展。

## 注意事项
- Menagerie 的 UR5e MJCF 可能使用 `<include>` 引用 mesh 文件路径，需确保相对路径正确
- MuJoCo 的 `mimic` 元素语法需确认版本兼容性（MuJoCo 3.x 支持）
- 夹爪手指的碰撞几何体略大于视觉几何体，避免穿透
- UR5e 基座位置需通过试验确定，使工作空间覆盖桌面中心区域
