## 目标
实现带推动约束的 RRT（快速随机探索树）路径规划算法，在状态空间中为推物任务生成无碰撞路径（末端位置序列）。

## 前置条件
- S03 完成：`SimController` 可用，碰撞检测、状态查询接口就绪

## 实现细节

### 1. 状态空间定义

推动任务的状态建模为：
```
state = (x_obj, y_obj, x_ee, y_ee, z_ee)
```
- `(x_obj, y_obj)`：物体在桌面上的位置（2D，假设物体不高，简化为桌面投影）
- `(x_ee, y_ee, z_ee)`：末端推板位置（3D，z_ee 固定为物体半高 ≈ 0.02m）

**推动约束**：推板必须与物体接触。简化假设为——推板始终从物体的指定方向接触，例如：
```
x_ee = x_obj + offset_x
y_ee = y_obj + offset_y
```
其中 `(offset_x, offset_y)` 为推板中心相对物体中心的偏移，取决于推的方向。在 RRT 扩展时，新状态需满足该接触约束。

简化方案（初期）：**固定推的方向为从物体 -Y 侧向 +Y 方向推**，则：
```
x_ee = x_obj
y_ee = y_obj - contact_offset  # contact_offset ≈ 物体半径+推板半宽 ≈ 0.04m
z_ee = 0.02  # 推板底面略高于桌面
```

### 2. 碰撞检测函数

需要检测三类碰撞：

#### 2.1 物体 ↔ 障碍物
- 使用包围体（球体/长方体）与障碍物几何体的分离轴定理（SAT）或简化为圆-矩形距离检测
- 物体为球体（radius=0.02m）时：直接计算球心到障碍物表面最近距离
- 物体为方块时：使用 AABB-OBB 或圆近似简化

#### 2.2 推板 ↔ 障碍物
- 推板视为矩形包围盒（0.04m×0.04m 投影到桌面）
- 检测与障碍物的重叠

#### 2.3 推板 ↔ 工作空间边界
- 推板的 XY 坐标必须在机械臂限位范围内：
  - X ∈ [-0.5, 0.5]
  - Y ∈ [-0.3, 0.3]
- 额外留 0.01m 安全余量

### 3. RRT 算法实现

```python
class PushRRT:
    def __init__(self, obstacles, workspace_bounds, collision_margin=0.01):
        """初始化规划器"""

    def plan(self, start_obj_pose, target_obj_pose, max_iter=5000, step_size=0.01):
        """
        规划推动路径
        返回: [(x_obj, y_obj, x_ee, y_ee, z_ee), ...] 或 None（规划失败）
        """

    def _sample(self, goal_bias=0.1):
        """随机采样状态（10% 概率直接采样目标）"""

    def _nearest(self, tree, sample):
        """找树中最近节点（欧氏距离）"""

    def _steer(self, from_state, to_state, step_size):
        """从 from_state 向 to_state 方向扩展一步"""

    def _is_collision_free(self, state):
        """检查状态是否无碰撞"""

    def _extract_path(self, tree, node_idx):
        """从终点回溯提取路径"""
```

#### 算法流程
1. 初始化树，根节点为起始状态
2. 循环（最多 max_iter 次）：
   - 随机采样一个目标状态（物体位置 `(x_obj, y_obj)`，10% 概率直接采样目标位置）
   - 找到树中最近节点
   - 从最近节点向采样点方向扩展一步（步长 ≈ 0.01m）
   - 根据推动约束计算对应的 `(x_ee, y_ee, z_ee)`
   - 碰撞检测：新状态是否无碰撞
   - 若无碰撞，加入树
   - 若新节点距目标 < 0.01m，提取路径并返回
3. 达到最大迭代次数返回失败

### 4. 路径平滑
RRT 原始路径通常比较曲折，需后处理：
- 使用**短切法**（shortcut）：随机选取路径上两点，尝试直线连接，若直线无碰撞则删除中间点
- 迭代 100-200 轮直到路径简化
- 再用 B-spline 或移动平均平滑

### 5. 稠密采样
- 平滑后路径按 0.005m（5mm）间距重新采样
- 50Hz 仿真下每步物体移动约 5mm，保证运动连续

## 验证标准
- [ ] 对简单场景（无障碍物），RRT 可在 1 秒内生成从起点到终点的路径
- [ ] 对含障碍物场景，路径全程不穿过障碍物
- [ ] 路径末端物体位置距目标 < 0.01m
- [ ] 路径经平滑后段数减少 30% 以上
- [ ] 稠密采样后相邻点间距 ≤ 0.005m
- [ ] 100 次随机起终点规划成功率 ≥ 90%
- [ ] 规划器输出格式：`[(x_obj, y_obj, x_ee, y_ee, z_ee), ...]` 可直接传给 S03 控制器执行

## 注意事项
- 碰撞检测的性能至关重要——RRT 需要大量碰撞查询。预计算障碍物的 SDF（符号距离场）或使用空间哈希网格加速
- 对于方块和锥体物体的碰撞，可简化为外接圆半径（0.028m）以统一处理
- 推动方向的简化假设（固定从 -Y 推）在障碍物密集时可能不可行——后续可扩展为多方向推动或推板可绕物体切换接触面
- 规划失败时需返回 None 并记录失败原因，供上层调用者处理（丢弃该任务重新采样）
