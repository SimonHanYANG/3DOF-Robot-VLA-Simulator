### 2. 拖拽末端推板

使用 `@react-three/drei` 的 `TransformControls`：

```tsx
// PushPlate.tsx 中
import { TransformControls } from "@react-three/drei";

function PushPlate() {
  const [dragging, setDragging] = useState(false);
  const send = useWebSocketSend();

  return (
    <TransformControls
      mode="translate"
      // 限制拖拽轴为 XYZ（与关节轴对齐）
      showX={true} showY={true} showZ={true}
      // 限制拖拽范围
      translationLimits={[
        [-0.5, 0.5],  // X
        [-0.3, 0.3],  // Y
        [0.0, 0.4],   // Z
      ]}
      onObjectChange={(e) => {
        // 拖拽中：实时更新本地位置（视觉跟随）
        // 松手时：发送 set_ee_pose 到后端
      }}
      onPointerDown={() => setDragging(true)}
      onPointerUp={() => {
        setDragging(false);
        // 发送当前位置到后端
        send({ type: "set_ee_pose", x, y, z });
      }}
    >
      <mesh>
        <boxGeometry args={[0.04, 0.005, 0.04]} />
        <meshStandardMaterial color="orange" />
      </mesh>
    </TransformControls>
  );
}
```

**拖拽约束**：
- 推板只能在 XYZ 三个轴向移动（`TransformControls mode="translate"`）
- 拖拽范围裁剪到限位内
- 拖拽时暂停物理仿真（发送 `set_ee_pose` 后后端将关节直接设位）
- 推板高亮（发光边框）表示可拖拽

### 3. 任务设置面板

三种设置模式（工具栏按钮切换）：

#### 模式 A：面板设置
- 下拉菜单选择物体类型（球/方块/锥体）和颜色
- 输入框手动输入起始坐标 (x, y) 和目标坐标 (x, y)
- "应用"按钮发送 `set_task` 消息

#### 模式 B：点击设置
- 点击"设置起点"按钮 → 进入起点设置模式
- 在桌面上点击（通过 `raycaster`） → 起点标记出现（小球）
- 点击"设置目标"按钮 → 进入目标设置模式
- 在桌面上点击 → 目标标记出现（小旗标/红色球）
- 确认后发送 `set_task`

#### 位置合法性校验
- 前端预检：坐标是否在限位范围内、是否与障碍物重叠
- 后端最终校验：通过 WebSocket 返回结果
- 不合法时：红色提示，标记无法放置

### 4. 点击桌面放置（Raycaster）

```tsx
// 使用 drei 的 useThree + three.js Raycaster
function useClickOnTable(send) {
  const { camera, raycaster, gl } = useThree();

  const handleClick = (event) => {
    const mouse = new THREE.Vector2(
      (event.clientX / window.innerWidth) * 2 - 1,
      -(event.clientY / window.innerHeight) * 2 + 1,
    );
    raycaster.setFromCamera(mouse, camera);
    // 检测与桌面平面的交点（Z-up 约定：桌面法线为 Z 轴，桌面在 z=0.01）
    const tablePlane = new THREE.Plane(new THREE.Vector3(0, 0, 1), -0.01);
    const intersect = new THREE.Vector3();
    raycaster.ray.intersectPlane(tablePlane, intersect);
    if (intersect) {
      // Z-up 约定：intersect.x → 桌面 X, intersect.y → 桌面 Y
      return { x: intersect.x, y: intersect.y };
    }
    return null;
  };
  // ...
}
```

### 5. 模型加载 UI

- 文件选择器或路径输入框
- 下拉菜单选择模型类型：OpenVLA / ACT / π0 / π0.5
- 输入 checkpoint 路径
- 点击"加载模型" → 发送 `load_model` → 等待后端确认
- 加载中显示 spinner，加载完成显示 ✅

### 6. 推理控制

- **开始按钮**（▶）：发送 `start_inference` → 状态变为 "推理中"
- **停止按钮**（■）：发送 `stop_inference` → 状态回到 "模型已加载"
- **速度选择器**：0.5x / 1x / 2x → 发送 `set_speed`，调整后端仿真步进频率或前端动画播放速率

## 注意事项
- `TransformControls` 拖拽事件中需区分"拖拽中"和"松手"——只在松手时发送 WebSocket 消息，避免后端被高频请求淹没
- 桌面点击检测需排除点击到 UI 面板和物体的情况（用 `event.stopPropagation()` 或检测点击目标）
- 位置合法性校验在前端做初步检查（简单的范围检查），后端做物理层面的碰撞检查
- 若桌面点击和 OrbitControls 的旋转操作冲突，检查 OrbitControls 的 `enabled` 属性——在"设置模式"下临时禁用旋转
