# UR5 取放仿真平台 — 分步实现指南

## 项目简介

本项目旨在构建一个**仿真→数据采集→模型训练→模型推理→可视化**一体化平台。核心目标是：

1. **仿真环境**：基于 MuJoCo 构建 UR5e 六自由度机械臂+平行二指夹爪取放场景，包含多种物体（立方体/球体/圆柱体，后续扩展杯/瓶/碗）
2. **数据生成**：使用抓取规划+取放轨迹生成高质量专家轨迹，录制为结构化数据集
3. **模型训练**：使用自采数据**重新训练/微调** OpenVLA、ACT、π0/π0.5 等主流 VLA 模型
4. **闭环推理**：加载自训模型，在仿真环境中进行闭环推理测试
5. **可视化**：通过 React + Three.js 前端实时 3D 展示推理过程，支持拖拽交互

## 系统架构

```
┌────────────────────────────────┐
│     前端 UI (React + R3F)       │
│  3D 场景渲染 | 交互面板 | 动画   │
└──────────┬─────────────────────┘
           │ WebSocket (JSON)
┌──────────▼─────────────────────┐
│     后端服务 (FastAPI)          │
│  仿真接口 | 推理管理 | 任务调度   │
└──────────┬─────────────────────┘
           │
┌──────────▼─────────────────────┐
│   仿真核心 (MuJoCo)             │
│  UR5e 机械臂 | 夹爪 | 物体      │
│  IK 求解器 | 碰撞检测           │
└────────────────────────────────┘

数据流：仿真 → 抓取规划 → 轨迹录制 → 数据集 → 模型训练 → 推理 → 可视化
```

## 动作空间

**7D 笛卡尔增量 + 夹爪**：
- `(dx, dy, dz)`：末端位置增量（单位：m，范围 ±0.02m）
- `(droll, dpitch, dyaw)`：末端旋转增量（单位：rad，范围 ±0.1rad）
- `gripper_open`：夹爪开合（0=闭合，1=张开）

控制器内部通过逆运动学（IK）将笛卡尔增量转换为关节目标。

## 使用说明

### 如何阅读
1. 先看本 README 了解项目全貌
2. 按步骤编号顺序阅读各步骤文件
3. 每个步骤文件包含：目标、前置条件、实现细节、关键文件、验证标准

### 如何更新状态
- 开始某步骤时：将该步骤文件头部的状态改为 `🟡 进行中`，同步更新上表
- 完成某步骤时：将该步骤文件头部的状态改为 `🟢 已完成`，记录完成日期，同步更新上表
- 遇到阻塞时：在步骤文件中添加 `## 阻塞问题` 小节，记录原因

### 状态标识说明
- 🔴 未开始：该步骤尚未着手
- 🟡 进行中：正在实现中
- 🟢 已完成：已通过验证标准
- ⚪ 已跳过：经评估决定跳过该步骤
