# 3DOF 推物避障仿真平台 — 分步实现指南

## 项目简介

本项目旨在构建一个**仿真→数据采集→模型训练→模型推理→可视化**一体化平台。核心目标是：

1. **仿真环境**：基于 MuJoCo 构建 3DOF（XYZ 三直线轴）机械臂推物场景，包含多种物体（球/方块/锥体）与固定障碍物
2. **数据生成**：使用 RRT 规划算法生成高质量专家推动轨迹，录制为结构化数据集
3. **模型训练**：使用自采数据**重新训练/微调** OpenVLA、ACT、π0/π0.5 等主流 VLA 模型
4. **闭环推理**：加载自训模型，在仿真环境中进行闭环推理测试
5. **可视化**：通过 React + Three.js 前端实时 3D 展示推理过程，支持拖拽交互

## 系统架构

```
┌────────────────────────────────┐
│     前端 UI (React + R3F)       │
│  3D 场景渲染 | 拖拽交互 | 动画   │
└──────────┬─────────────────────┘
           │ WebSocket (JSON)
┌──────────▼─────────────────────┐
│     后端服务 (FastAPI)          │
│  仿真接口 | 推理管理 | 任务调度   │
└──────────┬─────────────────────┘
           │
┌──────────▼─────────────────────┐
│   仿真核心 (MuJoCo)             │
│  3DOF 机械臂 | 物体 | 障碍物    │
└────────────────────────────────┘

数据流：仿真 → RRT 规划 → 轨迹录制 → 数据集 → 模型训练 → 推理 → 可视化
```

## 使用说明

### 如何阅读
1. 先看本 README 了解项目全貌
2. 按步骤编号顺序阅读各步骤文件
3. 每个步骤文件包含：目标、前置条件、实现细节、关键文件、验证标准

### 如何更新状态
- 开始某步骤时：将该步骤文件头部的状态改为 `🟡 进行中`，同步更新上表
- 完成某步骤时：将该步骤文件头部的状态改为 `🟢 已完成`，记录完成日期，同步更新上表
- 遇到阻塞时：在步骤文件中添加 `## 阻塞问题` 小节，记录原因

### 状态标识说明
- 🔴 未开始：该步骤尚未着手
- 🟡 进行中：正在实现中
- 🟢 已完成：已通过验证标准
- ⚪ 已跳过：经评估决定跳过该步骤

### 文件命名规范
- `README.md` — 本索引文件
- `01-xxx.md` 至 `20-xxx.md` — 步骤文件，编号对应步骤 S01-S20
- 文件名使用小写英文+连字符，内容全部使用中文
