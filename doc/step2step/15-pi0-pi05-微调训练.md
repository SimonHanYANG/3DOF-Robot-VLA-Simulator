## 实现细节

### 1. π0 模型概述

π0（Pi Zero）是 Physical Intelligence 提出的 VLA 模型：
- **架构**：基于流匹配（flow matching）的扩散模型
- **输入**：多模态（图像 + 语言指令 + 机器人状态）
- **输出**：连续动作（7D）
- **特点**：支持多视图输入（顶视 + 腕部相机）

### 2. 双视图输入

π0 的输入包含两个相机的图像：
- `top_image`: 224×224×3 顶视图
- `wrist_image`: 224×224×3 腕部相机

```python
class Pi0Dataset(torch.utils.data.Dataset):
    def __init__(self, jsonl_path):
        self.samples = []
        with open(jsonl_path) as f:
            for line in f:
                self.samples.append(json.loads(line))

    def __getitem__(self, idx):
        sample = self.samples[idx]
        return {
            "top_image": decode_image(sample["images"]["top"]),
            "wrist_image": decode_image(sample["images"]["wrist"]),
            "instruction": sample["instruction"],
            "state": np.array(sample["states"][0]),      # (6,) 初始关节状态
            "actions": np.array(sample["actions"]),       # (T, 7) 动作序列
        }
```

### 3. 动作空间

π0 输出连续 7D 动作，无需离散化：
```
action = (dx, dy, dz, droll, dpitch, dyaw, gripper_open)
```

### 4. 微调策略

- 使用 LoRA 微调语言模型部分
- 视觉编码器冻结或低学习率微调
- 扩散模型的动作预测头全参数微调

### 5. 训练配置

```yaml
# models/training/configs/pi0_config.yaml
model:
  action_dim: 7
  num_views: 2      # top + wrist
  image_size: 224

training:
  epochs: 30
  batch_size: 16
  lr: 1.0e-4
  lr_backbone: 1.0e-5
  weight_decay: 0.01
  diffusion_steps: 10

data:
  train_path: "data/processed/pi0/train.jsonl"
  val_path: "data/processed/pi0/val.jsonl"
```
