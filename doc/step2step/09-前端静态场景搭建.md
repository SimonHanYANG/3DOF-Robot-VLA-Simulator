# S09 — 前端静态场景搭建

**状态**：🔴 未开始
**阶段**：四、前端界面
**依赖**：无（可独立开发，仅需知道场景几何参数）

## 目标
使用 React + Vite + React Three Fiber (R3F) 搭建前端项目，渲染静态 3D 场景：桌面、3DOF 机械臂（简化几何表示）、物体、障碍物、限位线框。

## 前置条件
- Node.js ≥ 18，npm ≥ 9 已安装
- 了解 S02 中的场景几何参数（物体尺寸、限位范围等）

## 实现细节

### 1. 项目初始化

```bash
npm create vite@latest frontend -- --template react-ts
cd frontend
npm install three @react-three/fiber @react-three/drei
npm install -D @types/three
```

### 3. 组件详细设计

#### 3.1 场景整体 (`Scene.tsx`)
```tsx
<Canvas up={[0, 0, 1]} camera={{ position: [0.5, -0.3, 0.6], fov: 50 }}>
  <Lights />
  <Table />
  <WorkspaceBounds />
  <Arm />
  <Obstacles />
  <Object3D />
  <TargetMarker />
  <Grid />
  <OrbitControls />  {/* drei 提供，S10 配置 */}
</Canvas>
```

#### 3.2 桌面 (`Table.tsx`)
- 尺寸：1.2m × 0.8m × 0.02m
- 材质：浅灰色 `meshStandardMaterial`，粗糙度 0.8
- 位置：几何体中心在 y=-0.01（桌面表面在 y=0）

#### 3.3 机械臂 (`Arm.tsx`)
三个滑台用嵌套的 `group` 表示，每个 group 在对应轴上平移：

```tsx
// 伪结构
<group position={[jointX, 0, 0]}>       {/* X 滑台 */}
  <group position={[0, jointY, 0]}>     {/* Y 滑台 */}
    <group position={[0, 0, jointZ]}>   {/* Z 滑台 */}
      <PushPlate />                      {/* 推板 */}
    </group>
    {/* Y 滑台导轨几何体 */}
  </group>
  {/* X 滑台导轨几何体 */}
</group>
```

- 导轨用细长 Box 表示
- 滑块用略大的 Box 表示
- 材质：金属灰 `meshStandardMaterial({ metalness: 0.8, roughness: 0.4 })`

#### 3.4 物体 (`Object3D.tsx`)
根据类型渲染不同几何体：
- 球体：`<sphereGeometry args={[0.02]} />`
- 立方体：`<boxGeometry args={[0.04, 0.04, 0.04]} />`
- 锥体：`<coneGeometry args={[0.02, 0.04, 16]} />`
- 材质颜色根据物体颜色属性设置

#### 3.5 障碍物 (`Obstacles.tsx`)
- 圆柱体：`<cylinderGeometry args={[0.03, 0.03, 0.1, 32]} />`
- 长方体：`<boxGeometry />`
- 材质：半透明黄色 `meshStandardMaterial({ color: "yellow", transparent: true, opacity: 0.5 })`

#### 3.6 限位范围 (`WorkspaceBounds.tsx`)
- X ∈ [-0.5, 0.5], Y ∈ [-0.3, 0.3], Z ∈ [0.0, 0.4]
- 使用 `<Edges>` 或 `<Line>` 绘制线框立方体
- 颜色：白色虚线

### 4. 坐标系统
- **统一使用 Z-up 约定**，与 MuJoCo 一致：X = 桌面长方向，Y = 桌面宽方向，Z = 高度
- Three.js 默认 Y-up，需在 Canvas 中设置 `up={[0, 0, 1]}` 切换为 Z-up
- 前端所有组件直接使用 MuJoCo 坐标 (x, y, z)，无需转换映射
- 世界缩放：1 单位 = 1 米

### 5. 光照 (`Lights.tsx`)
- 环境光：`<ambientLight intensity={0.4} />`
- 主方向光：`<directionalLight position={[5, 10, 5]} intensity={0.8} />`
- 补光：`<directionalLight position={[-3, 5, -3]} intensity={0.3} />`

## 注意事项
- Three.js 默认 Y-up，本项目通过 `<Canvas up={[0, 0, 1]}>` 统一切换为 Z-up，与 MuJoCo 坐标完全一致，前端所有组件直接使用 (x, y, z) 无需转换
- 初始状态下关节位置设为 (0, 0, 0.1)，物体放在默认位置
- 物体位置和关节位置使用 React state 管理（S10 改为 Zustand 全局状态）
