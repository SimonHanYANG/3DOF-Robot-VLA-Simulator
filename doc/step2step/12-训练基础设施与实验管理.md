### 3. Hydra 配置管理

使用 Hydra 管理训练超参数，支持命令行覆盖：

```yaml
  dataset_path: "data/processed/"

  wandb_project: "3dof-arm-vla"

  eval_interval: 500      # 每 N 步评估一次

  device: "cuda"

  gradient_accumulation_steps: 1
```

### 4. WandB 实验追踪

```python
# utils/logger.py
import wandb

class ExperimentLogger:
    def __init__(self, config: dict, project: str, run_name: str = None):
        self.use_wandb = config.get("use_wandb", True)
        if self.use_wandb:
            wandb.init(project=project, config=config, name=run_name)
        self.global_step = 0

    def log(self, metrics: dict, step: int = None):
        if step is not None:
            self.global_step = step
        if self.use_wandb:
            wandb.log(metrics, step=self.global_step)
        # 同时输出到控制台
        print(f"[Step {self.global_step}] " +
              " | ".join(f"{k}: {v:.4f}" for k, v in metrics.items()))

    def watch_model(self, model):
        if self.use_wandb:
            wandb.watch(model, log="gradients", log_freq=100)
```

### 5. Checkpoint 管理

```python
# utils/checkpoint.py
import torch
import yaml
from pathlib import Path

def save_checkpoint(model, optimizer, scheduler, epoch, step,
                    metrics: dict, save_dir: Path, is_best: bool = False):
    checkpoint = {
        "epoch": epoch,
        "global_step": step,
        "model_state_dict": model.state_dict(),
        "optimizer_state_dict": optimizer.state_dict(),
        "scheduler_state_dict": scheduler.state_dict() if scheduler else None,
        "metrics": metrics,
    }
    # 定期保存
    save_path = save_dir / f"checkpoint-{step}.pt"
    torch.save(checkpoint, save_path)
    # 最佳模型覆盖保存
    if is_best:
        torch.save(checkpoint, save_dir / "best.pt")
    # 保存配置快照
    return save_path
```

### 6. 模型权重目录规范

每次训练运行在 `models/checkpoints/{model_name}/run_{timestamp}/` 下创建独立目录：
- 命名：`run_20260101_1430`（日期+时间）
- 包含：config.yaml（完整训练配置）、所有 checkpoint、训练日志、评估结果

## 注意事项
- JAX 的安装需与 CUDA 版本严格匹配，建议查看 [JAX 官方安装指南](https://jax.readthedocs.io/en/latest/installation.html)
- 不同模型可能需要不同的 PyTorch 版本——OpenVLA 和 ACT 对 PyTorch 版本敏感，建议使用与官方推荐一致的版本
- 如果 GPU 显存不足（< 24GB），需要考虑使用 LoRA 微调（OpenVLA）、梯度累积、减小 batch size 等策略
- WandB 是可选的，如果不需要可仅使用 TensorBoard
- 所有随机种子固定（seed=42），确保实验可复现
