核心公式：`dq = J^T (J J^T + λ²I)^{-1} e`

其中：
- `J` 是 6×N Jacobian 矩阵（`mj_jac` 计算）
- `e` 是 6D 误差向量（3 位置 + 3 角度轴旋转）
- `λ` 是阻尼系数（默认 0.01）

### 2. 误差计算

#### 位置误差
```

```

#### 姿态误差
使用角轴表示：
```python
R_err = R_target @ R_current.T           # 误差旋转矩阵
```

完整误差向量：`e = [e_pos; e_rot]` (6,)

## 注意事项
- UR5e 的 6×6 Jacobian 在奇异点附近可能病态，阻尼系数 λ=0.01 可避免数值爆炸
- MuJoCo 的四元数格式为 (w, x, y, z)，与 scipy 默认 (x, y, z, w) 不同，需转换
- 每次 IK 迭代需调用 `mj_forward` 更新 Jacobian
- 腕部奇异（wrist_2 ≈ 0°）时 IK 可能不收敛，需增大阻尼或改用伪逆
