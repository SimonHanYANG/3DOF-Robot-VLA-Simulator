## 实现细节

### 1. SimController 类设计

```python
class SimController:
    """3DOF 推物仿真环境控制器"""

    def __init__(self, scene_path: str, render_size: tuple = (224, 224)):
        """加载场景，初始化模型和数据"""

    def reset(self, obj_type: str, obj_pos: tuple, target_pos: tuple):
        """重置场景：放置物体到初始位姿，设置目标位置"""

    def step(self, action: tuple) -> dict:
        """执行一步仿真（0.02s），应用末端位移，返回观测"""

    def set_ee_pose(self, x: float, y: float, z: float):
        """直接设置末端位置（用于拖拽）"""

    def get_state(self) -> dict:
        """获取完整场景状态"""

    def get_camera_images(self) -> dict:
        """从两个相机渲染 RGB 图像"""

    def check_collision(self) -> list:
        """检测当前碰撞事件"""

    def is_done(self) -> tuple:
        """检查终止条件"""
```

### 2. 核心功能详细说明

#### 2.1 场景加载与初始化（`__init__`）
- 使用 `mujoco.MjModel.from_xml_path()` 加载 XML
- 创建 `mujoco.MjData` 实例
- 初始化渲染器：`mujoco.Renderer(model, height, width)`
- 存储关节 ID、物体 body ID、障碍物 ID 等索引，避免每步查找
- 记录限位值作为类属性

#### 2.2 位置控制（`set_ee_pose` / `step`）
- **直接设位**：`set_ee_pose(x, y, z)` 将 XYZ 三个关节的 `ctrl` 值直接设为目标位置，然后调用 `mj_step` 执行。用于前端拖拽和绝对位置控制。
- **增量位移**：`step(dx, dy, dz)` 将当前关节位置加上增量，裁剪到限位范围后执行。用于模型推理输出的增量动作。
- 限位裁剪：每次执行前强制 `clip(ctrl, joint_range[:,0], joint_range[:,1])`

#### 2.3 状态查询（`get_state`）
返回字典包含：
```python
{
    "ee_pose": (x, y, z),         # 末端当前位置
    "ee_velocity": (vx, vy, vz),  # 末端当前速度
    "joint_positions": [...],     # 各关节位置
    "obj_pose": {
        "position": (x, y, z),       # 物体位置
        "quaternion": (qw, qx, qy, qz),  # 物体旋转（四元数）
    },
    "obj_velocity": (...),        # 物体速度
    "target_pose": (x, y),        # 目标位置（桌面坐标）
    "time": float,                # 仿真时间
}
```

注意：物体旋转信息（四元数）在推方块和锥体时很重要——前端需要根据旋转正确渲染物体朝向。`get_state()` 返回的 `obj_pose` 使用字典而非元组，方便后续按字段取用。

#### 2.4 碰撞检测（`check_collision`）
- 遍历 `mjData.contact` 数组
- 解析每对碰撞体（`geom1` → `geom2`）
- 分类为：物体↔障碍物、推板↔障碍物、推板↔桌面边界
- 返回碰撞事件列表，每项包含：`{body_A, body_B, position, frame}`

#### 2.5 物体重置（`reset`）
- 将指定类型物体的 body 位姿设到 `obj_pos`
- 确保初始位姿不与其他物体/障碍物重叠（简单采样+碰撞检测循环）
- 将机械臂设到安全初始位姿（例如物体正上方 0.1m）
- 记录目标位置供后续判断
- 将目标位姿以视觉标记（小半透明球）呈现在场景中（向场景动态添加一个 site 或 geom）——注意 MuJoCo 模型的静态性，可能需要预先在 XML 中定义 target site，仅更新其位置

#### 2.6 终止条件（`is_done`）
返回 `(done, success, info)`：
- **成功**：物体中心与目标位置距离 < 0.01m（1cm）
- **失败**：物体碰障碍物、机械臂超限位、超时（> 200 步 = 4 秒）
- **进行中**：以上条件均不满足

### 3. 渲染接口
- `get_camera_images()`：返回 `{"top": np.ndarray, "angle": np.ndarray}`，均为 (224, 224, 3) uint8 RGB
- 使用 `mujoco.Renderer` 的 `update_scene` + `render` 方法
- 可选：渲染时叠加目标位置标记（通过修改 scene 的装饰几何体）

### 4. 上下文管理器
实现 `__enter__` / `__exit__` 以支持 `with SimController(...) as sim:` 用法，确保渲染器资源正确释放。

## 注意事项
- MuJoCo 的位置控制通过 `data.ctrl[...]` 数组直接赋值，对应 XML 中 actuator 的顺序
- 首次加载场景后运行 `mj_forward` 获取初始状态
- 物体初始位姿采样时需确保在机械臂可达范围（X∈[-0.4,0.4], Y∈[-0.25,0.25]）内，且不与障碍物重叠
- 预留后续添加更多物体的扩展性——使用 body name 而非硬编码 ID
