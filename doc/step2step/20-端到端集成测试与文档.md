### 2. 异常处理

| 异常 | 处理 |
|------|------|
| 模型加载失败 | 返回 error，不崩溃 |
| GPU OOM | 卸载模型，发送 error |
| WebSocket 断连 | 清理连接，其他客户端不受影响 |
| 非法动作 (NaN) | 裁剪为零动作 |
| IK 不收敛 | 保持上一步关节目标 |
