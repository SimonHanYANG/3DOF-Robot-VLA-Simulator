## 目标
实现抓取位姿规划模块，根据物体类型和位置，生成顶部抓取的候选位姿（pre_grasp、grasp、finger_width）。支持立方体、球体、圆柱体，后续扩展到日常物体。

## 实现细节

### 1. GraspPose 数据结构

```python
from dataclasses import dataclass

@dataclass
class GraspPose:
    """抓取位姿定义"""
    pre_grasp_pos: np.ndarray    # (3,) 预抓取位置（物体上方 10cm）
    pre_grasp_quat: np.ndarray   # (4,) 预抓取姿态（wxyz）
    grasp_pos: np.ndarray        # (3,) 抓取位置
    grasp_quat: np.ndarray       # (4,) 抓取姿态
    finger_width: float          # 抓取时手指间距
    approach_dir: np.ndarray     # (3,) 接近方向（单位向量）
```

### 2. 顶部抓取策略

所有几何体默认使用**垂直向下抓取**（gripper Z 轴朝下）：

```python
# 标准顶部抓取姿态：夹爪从上方接近
# 夹爪局部坐标系：Z = 接近方向，Y = 手指开合方向
# 世界坐标系中 Z 轴向下 → 旋转矩阵：
R_top_down = np.array([
    [1,  0,  0],
    [0, -1,  0],
    [0,  0, -1]
])
```

### 3. 各物体类型的抓取参数

#### 立方体 (cube)
- **抓取位置**：物体中心上方，高度 = 物体半高 + 2mm
- **手指间距**：边长 × 0.8（留余量）
- **pre_grasp**：抓取位置 Z + 0.10m
- **旋转**：可绕 Z 轴随机旋转 0°/45°/90°/135°（增加多样性）

#### 球体 (sphere)
- **抓取位置**：球心上方，高度 = 球心 Z + 半径 × 0.3
- **手指间距**：直径 × 0.6
- **pre_grasp**：抓取位置 Z + 0.10m
- **旋转**：任意（球体对称）

#### 圆柱体 (cylinder)
- **抓取位置**：中心轴上方，高度 = 半高
- **手指间距**：直径 × 0.7
- **pre_grasp**：抓取位置 Z + 0.10m
- **旋转**：绕 Z 轴随机旋转（抓取方向影响稳定性）

## 注意事项
- 圆柱体的抓取方向应沿直径方向，避免沿切向抓取（不稳定）
- 立方体旋转角度应考虑 90° 对称性，减少无效采样
- 后续扩展日常物体时，需针对杯子（边缘抓取）、瓶子（柱面抓取）、碗（外沿抓取）设计不同策略
- 抓取位姿的 Z 高度需考虑物体尺寸差异，避免手指撞到桌面
