### 1. 末端轨迹曲线（渐变）

```tsx
// components/EndpointTrajectory.tsx
import { Line } from "@react-three/drei";
import { useMemo } from "react";

function EndpointTrajectory({ points }: { points: Vector3[] }) {
  // 使用渐变色彩：蓝（早期）→ 青 → 绿（近期）
  const colors = useMemo(() => {
    return points.map((_, i) => {
      const t = i / Math.max(points.length - 1, 1);
      return new THREE.Color(
        0.2 + t * 0.3,   // R
        0.4 + t * 0.6,   // G
        1.0 - t * 0.5,   // B
      );
    });
  }, [points]);

  if (points.length < 2) return null;

  return <Line points={points} lineWidth={2} vertexColors={colors} />;
}
```

特性：
- 仅保留最近 200 个轨迹点，旧的逐渐消失
- 轨迹始终在物体上方 0.005m，避免与桌面 Z-fighting
- 颜色从冷色渐变到暖色，指示时序

```tsx
// components/ObjectTrajectory.tsx
import { Line } from "@react-three/drei";

function ObjectTrajectory({ points }: { points: Vector3[] }) {
  // 使用 dashed 材质
  return (
    <Line
      points={points}
      color="orange"
      lineWidth={1.5}
      dashed

```

- 虚线区别于末端的实线轨迹
- 橙色便于区分
- 同时显示前 50 个历史点和所有点（可选切换）

### 3. 动作方向箭头

```tsx
// components/ActionArrow.tsx
import { useRef, useMemo } from "react";

function ActionArrow({ origin, direction, scale = 50 }: {
  origin: Vector3;
  direction: Vector3;
  scale: number;
}) {
  // 从末端位置绘制箭头表示 (dx, dy, dz)
  const target = useMemo(
    () => origin.clone().add(direction.clone().multiplyScalar(scale)),
    [origin, direction],
  );

  // 使用 drei 的 Arrow 或自定义
  return (
    <group>
      {/* 箭杆 */}
      <Cylinder
        args={[0.002, 0.002, direction.length() * scale, 8]}
        position={...}
        rotation={...}
      >
        <meshStandardMaterial color="limegreen" />
      </Cylinder>
      {/* 箭头 */}
      <Cone
        args={[0.006, 0.015, 8]}
        position={target.toArray()}
        rotation={...}
      >
        <meshStandardMaterial color="limegreen" />
      </Cone>
    </group>
  );
}
```

- 箭头长度映射动作大小，放大 50 倍便于观察（(dx,dy,dz) 通常 0.01-0.02m）
- 颜色：绿色表示正常动作
- 每步更新箭头位置和方向

```tsx
// components/ResultOverlay.tsx
function ResultOverlay({ result }: { result: "success" | "failure" | null }) {
  if (!result) return null;

  return (
    <div className={`result-overlay ${result}`}>
      {result === "success" ? (
        <>
          <span className="icon">✅</span>
          <span className="text">任务成功！</span>
          <span className="error">最终误差: {finalError.toFixed(1)} mm</span>
        </>
      ) : (
        <>
          <span className="icon">❌</span>
          <span className="text">任务失败</span>
          <span className="reason">{failureReason}</span>
        </>
      )}
    </div>
  );
}
```

成功时：绿色边框闪烁，显示最终误差
失败时：红色边框闪烁，显示失败原因

### 6. 播放速度面板

```tsx
// components/SpeedControl.tsx
function SpeedControl() {
  const speed = useSimulationStore(s => s.speed);
  const send = useWebSocketSend();

  const options = [
    { label: "0.5x", value: 0.5 },
    { label: "1x", value: 1.0 },
    { label: "2x", value: 2.0 },
  ];

  return (
    <div className="speed-control">
      {options.map(opt => (
        <button
          key={opt.value}
          className={speed === opt.value ? "active" : ""}
          onClick={() => send({ type: "set_speed", speed: opt.value })}
        >
          {opt.label}
        </button>
      ))}
    </div>
  );
}
```

## 注意事项
- 大量轨迹点（> 1000 点）可能影响渲染性能——限制保留最近 200 个末端轨迹点，物体轨迹保留全部但使用低复杂度线段
- 动作箭头放大倍数需平衡可见性与准确性——50 倍是一个经验值，使 0.01m 的动作显示为 0.5m 长的箭头
- 碰撞高亮的闪烁效果用 CSS animation 而非 R3F per-frame 更新，减少 GPU 负担
- 前端动画播放和物理仿真（后端）是两个独立循环——前端仅做视觉呈现，不参与物理计算
