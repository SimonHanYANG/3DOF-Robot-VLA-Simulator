## 实现细节

### 1. 项目目录结构
创建以下目录层级：

```
3DOFArm_VLA/
├── doc/                        # 文档
│   ├── project_design.md       # 总体设计文档（已存在）
│   └── step2step/              # 分步实现指南（本文件夹）
├── sim/                        # 仿真核心模块
│   ├── __init__.py
│   ├── assets/                 # MuJoCo XML 场景文件
│   ├── controller.py           # 仿真控制器（S03）
│   └── planner/                # RRT 规划器（S04-S05）
├── backend/                    # 后端服务
│   ├── __init__.py
│   ├── main.py                 # FastAPI 入口（S07）
│   ├── ws_handler.py           # WebSocket 处理（S07）
│   └── services/               # 业务逻辑（S08）
├── frontend/                   # 前端应用（S09）
├── models/                     # 模型相关
│   ├── __init__.py
│   ├── adapters/               # 模型适配器（S17）
│   ├── training/               # 训练脚本（S12-S16）
│   └── checkpoints/            # 训练好的模型权重
├── data/                       # 数据目录
│   ├── raw/                    # 原始 HDF5 轨迹数据（S06）
│   └── processed/              # 各模型格式化数据集（S13）
├── scripts/                    # 独立运行脚本
├── tests/                      # 测试
├── requirements.txt            # Python 依赖
└── README.md                   # 项目说明
```

### 2. Python 虚拟环境
- 使用 Python 3.10+（推荐 3.10 或 3.11，兼容大多数 VLA 模型依赖）
- 创建虚拟环境：`python -m venv venv`
- 激活后安装核心依赖

### 3. requirements.txt 内容
```
# 仿真核心

```

### 4. MuJoCo 安装验证
- `pip install mujoco`
- 运行简单测试脚本：创建一个空场景，加载并步进 1000 步
- 验证 `mujoco` 模块可正常导入，`mujoco.MjModel` 和 `mujoco.MjData` 可正常使用
