# S02 — MuJoCo 场景建模

**状态**：🔴 未开始
**阶段**：一、仿真核心搭建
**依赖**：S01（项目脚手架）

## 目标
使用 MuJoCo MJCF/XML 定义完整仿真场景：3DOF 滑台机械臂+推板末端、桌面、可推动物体（球/方块/锥体）、固定障碍物、双相机传感器。

## 前置条件
- S01 完成：MuJoCo 已安装并可运行

## 实现细节

### 1. 机械臂定义（MJCF）

**关节构型**：三直线滑台（X, Y, Z），使用 MuJoCo `slide` 关节。

```
世界原点（桌面中心）
  └── X 滑台基座 (slide joint, 沿 X 轴)
       └── Y 滑台基座 (slide joint, 沿 Y 轴)
            └── Z 滑台 (slide joint, 沿 Z 轴)
                 └── 推板末端 (固定连接)
```

**限位参数**（在 XML 中通过 `range` 属性设定）：
- X 关节：range="-0.5 0.5"（单位：米）
- Y 关节：range="-0.3 0.3"
- Z 关节：range="0.0 0.4"

**推板尺寸**：0.04m × 0.04m × 0.005m 的矩形薄板，固定于 Z 轴末端，无旋转自由度。

**驱动方式**：位置控制（`position` actuator），gear 参数设置足够大以保证能推动物体。

### 2. 桌面
- 尺寸：1.2m × 0.8m × 0.02m 的矩形平面
- 位置：z=0，桌面表面为 z=0.01（半高）
- 颜色：浅灰色
- 作为静态几何体（不参与动力学计算，仅碰撞检测）

### 3. 物体定义
| 类型 | 几何参数 | 初始位置范围 | 颜色 |
|------|----------|-------------|------|
| 球体 | radius=0.02m | 随机（S03 设置） | 红 |
| 立方体 | 0.04m 边长 | 随机 | 蓝 |
| 锥体 | 底半径 0.02m, 高 0.04m | 随机 | 绿 |

- 物体质心 Z 坐标 = 桌面表面高度(z=0.01) + 物体半高，例如球体(半径0.02m)：z=0.03m；方块(边长0.04m)：z=0.03m；锥体(高0.04m)：z=0.03m
- 每种物体支持多颜色变体（为后续 VLA 模型理解颜色属性做准备）

### 4. 固定障碍物
- 类型：圆柱体（radius=0.03m, height=0.1m）和长方体
- 数量：3-5 个
- 位置：硬编码在桌面上的固定坐标，分布在工作空间内但不阻塞全部通道
- 颜色：半透明黄色
- 所有障碍物为静态 body（无自由度的固定几何体）

建议障碍物布局示例：
```
# 圆柱位置 (x, y)
障碍物1: (0.15, 0.10)
障碍物2: (-0.20, -0.08)
障碍物3: (0.05, -0.15)
障碍物4: (-0.10, 0.18)
```

### 5. 相机传感器
| 名称 | 类型 | 位置 | 朝向 | 分辨率 |
|------|------|------|------|--------|
| `top_cam` | fixed | (0, 0, 0.8) | 垂直向下 (fovy=90°) | 224×224 |
| `angle_cam` | fixed | (0.4, -0.4, 0.5) | 45° 斜向下看向桌面中心 (fovy=60°) | 224×224 |

注：顶视相机高度 0.8m + fovy=90° 可覆盖约 1.6m × 1.6m 范围，足以看到 1.2m × 0.8m 的整个桌面。相机定义中需显式设置 `fovy` 属性，例如：
```xml
<camera name="top_cam" pos="0 0 0.8" xyaxes="1 0 0 0 1 0" fovy="90"/>
```

- 使用 MuJoCo 的 `<camera>` 标签
- 相机渲染模式：RGB

### 6. 摩擦与接触参数
- 桌面摩擦：μ=0.5（`friction` 属性）
- 物体与推板之间：μ=0.8
- 物体质量：0.05-0.1 kg，不宜过大以便推动
- 在物体 Z 轴施加轻微阻尼（`damping`），减少推动时的旋转/倾倒
- 考虑使用 MuJoCo 的 `condim` 和 `priority` 优化接触稳定性

### 7. 场景文件组织
```
sim/assets/
├── scene.xml              # 主场景（包含所有子组件）
├── arm.xml                # 3DOF 机械臂 + 推板
├── objects.xml            # 可推动物体模板
├── obstacles.xml          # 固定障碍物
└── cameras.xml            # 相机定义
```

## 关键文件
| 文件 | 说明 |
|------|------|
| `sim/assets/scene.xml` | 主场景 XML |
| `sim/assets/arm.xml` | 机械臂定义 |
| `sim/assets/objects.xml` | 物体模板 |
| `sim/assets/obstacles.xml` | 障碍物布局 |
| `sim/assets/cameras.xml` | 相机配置 |

## 验证标准
- [ ] `mujoco.viewer.launch_passive()` 可打开场景并看到完整的桌面+机械臂+物体+障碍物
- [ ] 物体和障碍物位置正确，无初始重叠
- [ ] 机械臂关节可在限位范围内自由移动
- [ ] 两个相机渲染的 RGB 图像尺寸为 224×224
- [ ] 机械臂推板与物体接触时产生合理的碰撞响应
- [ ] 物体在推动时基本保持平移（不倾倒）

## 注意事项
- MJCF 中 `slide` 关节的运动轴通过 `user` 或直接设置 `<joint>` 的 axis 定义
- 物体初始位置可在 XML 中设为 (0,0,0)，实际初始位姿由 S03 仿真控制器动态设定
- 若渲染画面全黑，检查光照设置（添加 `<light>` 标签）
- 推板的碰撞几何体建议略大于视觉几何体，避免物体"穿透"推板
