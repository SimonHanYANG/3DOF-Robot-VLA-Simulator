### 1. π0 / π0.5 模型概述

π0 系列是 Physical Intelligence 开发的通用机器人基础模型：
- π0（pi-zero）：基于大规模互联网预训练 + 机器人数据微调的 VLA 模型
- π0.5：π0 的改进版本，更好的多模态理解和动作预测
- 核心架构：视觉 Transformer + 语言模型 + 动作扩散头
- 输入：图像 + 自然语言指令 + 本体感知状态（可选）
- 输出：连续动作向量（末端增量位移或绝对位姿）

**重要说明**：π0 系列的代码和权重发布策略可能随时间变化。本步骤描述通用集成方案，具体实现需根据当时的官方 API/仓库调整。在 π0 尚未完全开源的情况下，可使用其 API 进行微调，或关注官方发布的最新微调工具。

### 3. 数据集适配

π0 系列模型基于 JAX 实现，数据加载应使用原生 Python 迭代器而非 PyTorch Dataset。根据实际可用的 π0 版本选择数据加载方式：

#### 方案 A：π0 使用 JAX 训练（原生方式）

```python
class Pi0Dataset:
    """将 S13 的 JSONL 数据转换为 π0 训练格式（JAX/原生迭代器）"""

    def __init__(self, jsonl_path: str, image_dir: str):
        self.samples = []
        with open(jsonl_path) as f:
            for line in f:
                self.samples.append(json.loads(line))
        self.image_dir = image_dir

    def __iter__(self):
        for sample in self.samples:
            image = Image.open(os.path.join(self.image_dir,
                                             sample["image_path"]))
            yield {
                "image": np.array(image),               # numpy 数组
                "instruction": sample["instruction"],
                "state": np.array(sample["state"]),      # 当前末端位置
                "action": np.array(sample["action"]),    # 目标增量位移
            }

    def __len__(self):
        return len(self.samples)
```

### 4. 微调训练循环

```python
def train_pi0(config, train_loader, val_loader):
    """π0 微调训练主循环（具体 API 调用取决于官方接口）"""

    model = PiZeroModel.from_pretrained(config.pretrained_path)
    optimizer = create_optimizer(model, config)
    logger = ExperimentLogger(config, project="3dof-arm-vla-pi0")

    for epoch in range(config.num_epochs):
        model.train()
        for batch in train_loader:
            # π0 的前向传播：输入图像+指令+状态 → 预测动作
            loss = model.compute_loss(
                images=batch["images"],
                instructions=batch["instructions"],
                states=batch["states"],
                target_actions=batch["actions"],
            )

            loss.backward()
            optimizer.step()
            optimizer.zero_grad()

            logger.log({"train/loss": loss.item()})

        # 验证
        val_loss = evaluate_pi0(model, val_loader)
        logger.log({"val/loss": val_loss})

        # 保存
        save_checkpoint(model, ...)
```

### 5. π0 独特的训练考虑

#### 动作扩散损失
π0 使用扩散模型生成动作，损失函数可能涉及：
- 扩散模型的噪声预测损失（MSE）
- 或连续动作的回归损失（L2）

#### 多模态输入
- 图像需经过特定的预处理（与预训练时一致）
- 指令文本需 tokenize（使用模型自带的 tokenizer）
- 本体感知状态编码（末端位置 → embedding）

#### 微调策略
- π0 参数量大（可能 > 10B），通常使用 LoRA 或仅微调动作头
- 冻结视觉编码器和语言骨干，仅微调动作解码部分
- 或使用 adapter 层（如 ViT-Adapter）

### 6. π0 与 π0.5 的差异处理

| 特性 | π0 | π0.5 |
|------|-----|------|
| 参数规模 | 较大 | 较小（优化后） |
| 推理速度 | 较慢 | 较快 |
| 动作精度 | 较高 | 略低但可接受 |
| 微调难度 | 需较多显存 | 相对轻量 |

建议：优先尝试 π0.5（部署友好），若性能不足再升级到 π0。
