## 实现细节

### 1. 取放轨迹阶段

完整取放分为 7 个阶段：

```
Home → Approach → Descend → Grasp → Lift → Transport → Place → Retreat
```

| 阶段 | 起点 | 终点 | 夹爪 | 说明 |
|------|------|------|------|------|
| Approach | 当前 EE | pre_grasp | 张开 | 移动到物体上方 |
| Descend | pre_grasp | grasp | 张开 | 垂直下降到抓取位置 |
| Grasp | grasp | grasp | 闭合 | 关闭夹爪，等待稳定 |
| Lift | grasp | grasp + (0,0,0.1) | 闭合 | 垂直上提 10cm |
| Transport | lift 终点 | place_pre | 闭合 | 水平移动到目标上方 |
| Place | place_pre | place | 闭合 | 下降到放置高度 |
| Release | place | place | 张开 | 张开夹爪，等待释放 |
| Retreat | place | home | 张开 | 回到 home 位姿 |

### 2. 笛卡尔空间轨迹插值

每个阶段内部使用线性插值：

```python
def interpolate_cartesian(start_pos, start_quat, end_pos, end_quat, n_steps):
    """
    笛卡尔空间线性插值（位置线性，姿态 SLERP）

    返回: [(pos, quat), ...] n_steps 个中间位姿
    """
    positions = np.linspace(start_pos, end_pos, n_steps)

    # SLERP for quaternion interpolation
    from scipy.spatial.transform import Rotation, Slerp
    rotations = Rotation.from_quat([start_quat_scipy, end_quat_scipy])
    slerp = Slerp([0, 1], rotations)
    quats = slerp(np.linspace(0, 1, n_steps))

    return positions, quats
```

### 3. 动作序列生成

```python
def generate_trajectory(sim_controller, grasp_pose, target_pos):
    """
    生成完整取放轨迹

    参数:
        sim_controller: SimController 实例
        grasp_pose: GraspPose 对象
        target_pos: 目标放置位置 (3,)

    返回:
        actions: list[np.ndarray] 每步 7D 动作
    """
    actions = []

    # 1. Approach: 当前 → pre_grasp
    actions += interpolate_to_pose(
        current_ee, grasp_pose.pre_grasp_pos, grasp_pose.pre_grasp_quat,
        gripper=1.0, speed=0.02  # 2cm/step
    )

    # 2. Descend: pre_grasp → grasp
    actions += interpolate_to_pose(
        grasp_pose.pre_grasp_pos, grasp_pose.grasp_pos, grasp_pose.grasp_quat,
        gripper=1.0, speed=0.01  # 下降慢一些
    )

    # 3. Grasp: 关闭夹爪
    actions += [np.array([0, 0, 0, 0, 0, 0, 0.0])] * 10  # 等待 10 步稳定

    # 4. Lift: 垂直上提
    lift_pos = grasp_pose.grasp_pos + np.array([0, 0, 0.1])
    actions += interpolate_to_pose(
        grasp_pose.grasp_pos, lift_pos, grasp_pose.grasp_quat,
        gripper=0.0, speed=0.02
    )

    # 5. Transport: 水平移动到目标上方
    place_pre = np.array([target_pos[0], target_pos[1], lift_pos[2]])
    actions += interpolate_to_pose(
        lift_pos, place_pre, grasp_pose.grasp_quat,
        gripper=0.0, speed=0.02
    )

    # 6. Place: 下降
    place_pos = np.array([target_pos[0], target_pos[1], target_pos[2] + 0.02])
    actions += interpolate_to_pose(
        place_pre, place_pos, grasp_pose.grasp_quat,
        gripper=0.0, speed=0.01
    )

    # 7. Release: 张开夹爪
    actions += [np.array([0, 0, 0, 0, 0, 0, 1.0])] * 10

    # 8. Retreat: 回到 home
    actions += interpolate_to_pose(
        place_pos, home_pos, home_quat,
        gripper=1.0, speed=0.02
    )

    return actions
```

### 4. 笛卡尔增量转换

轨迹生成的是目标位姿序列，需转换为 7D 增量动作：

```python
def pose_to_delta_action(current_pose, target_pose, gripper_cmd):
    """
    将目标位姿差转换为 7D 增量动作
    """
    pos_delta = target_pos - current_pos
    rot_delta = compute_rotation_delta(current_quat, target_quat)

    # 裁剪到安全范围
    pos_delta = np.clip(pos_delta, -0.02, 0.02)
    rot_delta = np.clip(rot_delta, -0.1, 0.1)

    return np.concatenate([pos_delta, rot_delta, [gripper_cmd]])
```

### 5. 轨迹验证

在 SimController 中重播生成的动作序列：
- 检查每个阶段的 IK 成功率
- 检查抓取后物体是否被举起（物体 z 增加）
- 检查放置后物体距目标距离
- 如验证失败，尝试调整抓取位姿重新生成

## 注意事项
- 下降和放置阶段速度应更慢（0.01m/step），避免撞击
- 夹爪闭合后需等待足够步数让物理稳定（至少 5-10 步）
- Transport 阶段保持高度 > 0.08m，避免物体碰桌面
- 若目标位置在障碍物附近，Transport 路径可能需要抬高
