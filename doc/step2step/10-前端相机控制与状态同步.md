## 实现细节

### 1. 相机控制

使用 `@react-three/drei` 的 `OrbitControls`：

```tsx
<OrbitControls
  target={[0, 0, 0.1]}      // 看向桌面中心略上方
  minDistance={0.2}          // 最近缩放距离
  maxDistance={1.5}          // 最远缩放距离
  maxPolarAngle={Math.PI / 2.2}  // 限制仰角，避免翻到底部
  enableDamping={true}
  dampingFactor={0.1}
/>
```

额外功能：
- 按 `R` 键重置视角（通过 `useKeyPress` hook）
- 双击物体将视角聚焦到该物体

### 2. 全局状态管理（Zustand）

```typescript
// store/simulationStore.ts
import { create } from "zustand";

interface SimulationState {
  // 末端位姿
  eePose: [number, number, number];
  // 物体位置 (x, y, z)
  objPosition: [number, number, number];
  // 物体旋转四元数 (qw, qx, qy, qz)
  objQuaternion: [number, number, number, number];
  // 目标位置
  targetPose: [number, number];
  // 任务状态
  taskState: "idle" | "task_set" | "model_loaded" | "inferring" | "done";
  // 模型输出动作
  lastAction: [number, number, number] | null;
  // 碰撞状态
  collision: boolean;
  // 物体类型与颜色
  objectType: string;
  objectColor: string;
  // 连接状态
  connected: boolean;

  // 更新方法
  updateFromStateMsg: (msg: StateUpdateMsg) => void;
  setConnected: (v: boolean) => void;
}
```

选择 Zustand 的理由：轻量、无 boilerplate、与 R3F 配合好（可直接在 `useFrame` 中订阅）。

### 3. WebSocket 客户端 Hook

```typescript
// hooks/useWebSocket.ts
export function useWebSocket(url: string) {
  const wsRef = useRef<WebSocket | null>(null);
  const setConnected = useSimulationStore(s => s.setConnected);
  const updateFromStateMsg = useSimulationStore(s => s.updateFromStateMsg);

  useEffect(() => {
    const ws = new WebSocket(url);
    wsRef.current = ws;

    ws.onopen = () => setConnected(true);
    ws.onclose = () => setConnected(false);
    ws.onerror = () => setConnected(false);

    ws.onmessage = (event) => {
      const msg = JSON.parse(event.data);
      switch (msg.type) {
        case "state_update":
          updateFromStateMsg(msg);
          break;
        case "inference_action":
          // S19 处理
          break;
        case "collision_event":
          // S19 处理
          break;
        case "done":
          // S19 处理
          break;
      }
    };

    return () => ws.close();
  }, [url]);

  // 发送消息的辅助函数
  const send = useCallback((msg: object) => {
    wsRef.current?.send(JSON.stringify(msg));
  }, []);

  return { send };
}
```

### 4. 场景与状态联动

各组件从 Zustand store 读取状态并更新 3D 对象：

```tsx
// Arm.tsx — 响应末端位置
function Arm() {
  const eePose = useSimulationStore(s => s.eePose);
  const [x, y, z] = eePose;

  return (
    <group>
      <group position={[x, 0, 0]}>
        {/* X 滑台 */}
        <group position={[0, y, 0]}>
          {/* Y 滑台 */}
          <group position={[0, 0, z]}>
            <PushPlate />
          </group>
        </group>
      </group>
    </group>
  );
}
```

```tsx
// Object3D.tsx — 响应物体位置和旋转
function Object3D() {
  const objPosition = useSimulationStore(s => s.objPosition);
  const objQuaternion = useSimulationStore(s => s.objQuaternion);
  const objType = useSimulationStore(s => s.objectType);
  const objColor = useSimulationStore(s => s.objectColor);

  const quaternion = useMemo(
    () => new THREE.Quaternion(objQuaternion[1], objQuaternion[2], objQuaternion[3], objQuaternion[0]),
    [objQuaternion]
  );

  return (
    <group position={objPosition} quaternion={quaternion}>
      {/* 根据 objType 渲染对应几何体 */}
    </group>
  );
}
```

注意：Three.js 的 `Quaternion` 构造函数参数顺序是 `(x, y, z, w)`，而 MuJoCo 输出的四元数是 `(qw, qx, qy, qz)`，需要转换顺序。

## 注意事项
- 图像解码为 data URL 后约增大 33%（base64 开销），224×224 图像作为 `<img>` 渲染可在浏览器中流畅显示
- Zustand store 更新频率为 25Hz，React 重渲染性能足够；如有性能问题可对 Arm/Object 组件使用 `React.memo`
- WebSocket 消息处理不要在 render 中做，全部在 `onmessage` 回调中处理完再更新 store
- 开发时可先用 `scripts/mock_ws_server.py` 提供模拟数据，不依赖后端
