### 2. 7D 动作执行（`step`）

```python
def step(self, action: np.ndarray) -> dict:
    """
    执行一步仿真

    参数:
        action: (7,) 数组
            [0:3] = (dx, dy, dz) 位置增量 (m)
            [3:6] = (droll, dpitch, dyaw) 旋转增量 (rad)
            [6] = gripper_open (0=闭合, 1=张开)

    返回:
        obs: 观测字典
    """
    # 1. 裁剪动作到安全范围
    action = np.clip(action, self.action_low, self.action_high)

    # 2. IK 转换：笛卡尔增量 → 关节目标
    success, target_q = ik_from_cartesian_delta(
        self.model, self.data,
        self.data.qpos[self.arm_qpos_idx],
        action[0], action[1], action[2],
        action[3], action[4], action[5]
    )

    # 3. 设置执行器目标
    self.data.ctrl[:6] = target_q       # 6 个关节
    self.data.ctrl[6] = action[6] * self.gripper_max  # 夹爪

    # 4. 仿真步进（多步让物理稳定）
    for _ in range(self.substeps):
        mujoco.mj_step(self.model, self.data)

    # 5. 返回观测
    return self.get_obs()
```

### 5. 抓取检测（`check_grasp`）

检测逻辑：
1. 遍历 `data.contact` 数组
2. 找到 `finger_left_geom` ↔ 目标物体 和 `finger_right_geom` ↔ 目标物体 的接触
3. 两个手指都有接触 → 返回 `True`

### 6. 终止条件（`is_done`）

返回 `(done, success, info)`：
- **成功**：物体高度 > 0.05m（被举起）且物体距目标 XY 距离 < 0.02m 且夹爪仍接触物体
- **失败**：物体掉出桌面、超时（> 500 步 = 10 秒）、IK 持续失败
- **进行中**：以上均不满足

### 7. 物体重置（`reset`）

- 将指定物体的 `qpos` 设到目标位姿（位置 + 单位四元数）
- 机械臂回到 home 位姿（所有关节 = 0，夹爪张开）
- 更新目标标记 site 位置
- 调用 `mj_forward` 刷新状态

## 注意事项
- IK 失败时保持上一步的关节目标，不跳变
- 夹爪执行器值范围需与 XML 中定义的 range 对应
- `substeps` 参数（默认 10-20）影响仿真稳定性和响应速度
- 物体 `freejoint` 的 qpos 是 7 维（3 位置 + 4 四元数），非 6 维
